# Contributing

Contributions should keep prompt templates structured, reusable, validated, and honest about system capabilities.

1. Create a focused branch from `main`.
2. Add tests for template parsing, variables, rendering, or validation changes.
3. Run `ruff check .`, the coverage-gated unit tests, and the prompt-library smoke check.
4. Never commit credentials, private prompts, or personal data.
5. Keep declared variables exactly aligned with template placeholders.
6. In the pull request, explain what changed, why it changed, and how it was tested.
