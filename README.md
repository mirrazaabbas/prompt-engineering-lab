# Prompt Engineering Lab

A reusable Python prompt-template library for building structured prompts with explicit variables, validation, and a simple interactive CLI.

## Features

- JSON-backed prompt library
- Declared-variable validation
- Placeholder consistency checks
- Missing/empty value validation
- Interactive template selection
- Reusable prompt rendering
- Automated tests and CI

## Run

```bash
python prompt_lab.py
```

## Included templates

- Research Assistant
- Content Writer
- Data Analyst
